### **_Vibrance is more than just the notch._**

**`Vibrance`** is a native cross-platform application developed for Windows 22H2+, macOS and Linux operating systems. Powered by our in-house user interface engine **[`vibranceUI`](https://github.com/project-vibrance/engine)**, this software serves as a bridge to support cross-platform interface theming across supported operating systems.

Currently developed by [59xa](https://github.com/59xa), [Mayibane10](https://github.com/Mayibane10), [NotMagniill](https://github.com/notmagniill) and `khhvtrav`. This project is still a work-in-progress, and will improve over time.
